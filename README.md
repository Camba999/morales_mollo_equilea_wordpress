📘 Guía de Instalación de WordPress + Extensiones

📌 Descripción

Este repositorio contiene una guía de instalación y configuración de WordPress en un entorno local, utilizando XAMPP, MySQL y phpMyAdmin.

La guía fue elaborada por 3 integrantes y presenta el procedimiento mediante explicaciones e imágenes para facilitar la comprensión de cada paso.

🎯 Objetivo

El objetivo de esta guía es proporcionar un material de apoyo para realizar la instalación y configuración de WordPress, desde la preparación del entorno local hasta la instalación de extensiones.

📄 Contenido

El repositorio contiene el siguiente documento:

📑 Guia de descarga de WordPress + Extensiones.pdf

El PDF incluye:

- Instalación de XAMPP.
- Configuración de Apache y MySQL.
- Creación de una base de datos mediante phpMyAdmin.
- Descarga e instalación de WordPress.
- Configuración inicial de WordPress.
- Instalación de Elementor.
- Instalación de Pro Elementor.
- Imágenes y explicaciones de los procedimientos.

Toda la información detallada y los pasos para realizar el proceso se encuentran dentro del PDF.
